## Claude Code MCPVault bridge

The repository's `AGENTS.md` contains the shared MCPVault onboarding protocol.
Follow it when MCPVault is connected. Claude Code reads this import because it
does not automatically load `AGENTS.md`. Configure the MCP server separately
with `claude mcp add` or the client's `.mcp.json`; the repository instructions
do not contain passwords or bearer tokens.
