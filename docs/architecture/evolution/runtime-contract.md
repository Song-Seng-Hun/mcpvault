# Runtime contract

Existing authentication is required; storage configuration is not a grant.
Only host code captures trusted feedback; MCP reports remain agent reports.
Bind feedback bytes, account, authority revision, task and session to receipts.
Pin delivered resource revisions; transmission is not retained context or success.
Verify results with code-owned checks, not client success flags or generated logs.
Never persist tokens, whole transcripts, hidden reasoning or raw tool payloads.
Recheck permission before and after awaited operations and before returning.
Keep interrupted writes and evidence; do not initialize corrupt histories.

## Evaluation

Freeze input, model, harness, resource and evaluator revisions before generating.
Keep baseline, candidate and skill-free trials distinct.
Static, synthetic, agent behavior and operational evidence are separate classes.
Agent/operational final comparisons require three paired trials.
Reject any safety failure or regression; require target repair or 10% median saving.
Include failed generation/evaluation costs; unknown usage cannot fund automation.
Private unseen checks are not public regression scenario descriptions.

## Harness and resources

Evolve data-only routing, optional skill count, bounded reads and optional reviews.
Security, hard filters, mandatory evidence, grading and budgets are not mutable.
Use existing source owners and exact-revision rollback; preserve manual edits.
Keep current-task versions; next-task changes do not override immediate revocation.
Recursive strategy proposals require 20 independently effect-verified cycles.
No recursive invocation, new models, paid APIs or background scheduler.
