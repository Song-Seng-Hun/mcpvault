## Required boundaries

- Current access, verified processing runtime, and source-only/synthesis mode
  are separate checks. Host configuration absent means diagnostic-only.
- Unknown classifications do not authorize public capture. Existing documents
  are not automatically enrolled or reclassified. Administrator/model names and
  maintenance grants are not compilation grants.
- Apply restrictions before any derived body. Inherit all original restrictions.
  No provider fallback, transcript harvesting, new inference service, autonomous
  model process, or automatic confidentiality relaxation.
- Pin exact revisions, explicit members/relations/concepts, rule version,
  authority, output revision, and last managed output fingerprint. Human changes
  or unmanaged existing output require review, never overwrite.
- Generation, checking, application and completion receipts are distinct. Reread
  and durable completion receipt are required. Resume validates applied content,
  never reapplies an old patch over changed output. Corrupt history is preserved.
- One worker/document, stable request IDs, three failures maximum, bounded queues
  and responses. Unchanged events do not generate repeated actions.
- Markdown/revisions remain authoritative; graph vocabulary is reused from
  `graph-contract.ts`, not redefined. Fixed MCP tools remain five.

## Acceptance and operations

Use the inherited one-worker verification supervisor, admission2.3GiB/reserve2GiB
(explicit user approval); never close user applications. Each bundle runs targeted
tests, build, full tests, independent review, diff/staged/secret checks, NAS-backed
deployment with rollback and live verification, then existing-branch commit/push.
No upstream contribution, PR, package/release publication, new branch or worktree.
Originals, world/economy and credentials are preserved. Telnet stays off; NAS
direct-write protection is outside scope.

Quality gates remain per-language Recall@5/MRR non-regression, required evidence
coverage +5pp at4000/12000 characters, and no extra negative false positives.
Unit checks do not establish model quality; incomplete evaluation never passes.
Automatic knowledge application stays disabled until its quality and host gates
are verified. Unchecked bundles are not shipped implementation.
