# Metadata completion, not skill approval

The contract already separates metadata completion from procedural release approval.
`metadata-completion-1` names the following audit-work criteria, not a host permission.
It applies to source-discovery fields only; reviewed derivative descriptors stay separate.

## Criteria

- Capture every current bundle member with source inventory and drift checks.
- Main reads each included text member before finalizing the field interpretation.
- Every required field has exact source evidence or a precise, bounded unknown reason.
- Domain, purpose, applicability, connections and examples describe actual retained scope.
- Preserve truncated procedures, missing runners and unverified declarations as gaps.
- Record all seven conditional impact axes; do not replace unknown with low risk.
- Keep policy/legal applicability, provenance and compatibility uncertainty explicit.
- Usage/co-use require observations; unknown is acceptable and never means zero.
- Validate descriptor bounds, source quotes and negative security cases.
- Recheck source fingerprints before writing the immutable completion record.

`reviewed-with-limitations` means these metadata criteria passed for those source bytes.
It does not prove semantic safety, execution compatibility, usefulness or live access.
Missing external references can be accurately described without fetching or executing them.
Uninspected actual bundle members prevent this completion criterion; inventory alone is insufficient.
Required missing procedures still block whole-skill release, not honest metadata completion.
No older draft is upgraded merely because this definition exists.

## Work index

Private immutable pages record metadata_pending, metadata_draft or reviewed-with-limitations.
Each reviewed/draft row links the exact evidence file hash and source fingerprint.
An index is published locally only after its pages; interrupted generations are not reset.
Re-reading a matching generation makes no new records or grants.
The work index is an audit aid, not a search catalog, approval registry or telemetry source.
Recheck source and current authority before the next operation; old enumeration is not availability.
Public reports disclose only task-authorized aggregate progress, not private source bodies.

Example: an absent runner can be correctly documented; it cannot be executed or called usable.
