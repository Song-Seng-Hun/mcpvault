## Guard defects found by static inspection

floor-guard promises no secret values but prints up to 120 characters from matching lines.
Its subprocess helper discards output on nonzero exit; no-index differences can vanish that way.
Later Git failures become empty input instead of exit 2, potentially producing a clean verdict.
Deleted-file paths lose test identity; table thresholds can match unrelated rows by empty prefix.
Threshold direction is not typed, and deleted floor bullets without replacements are not detected.
These are source/code discrepancies, not a dynamically executed exploit or verified replacement.
