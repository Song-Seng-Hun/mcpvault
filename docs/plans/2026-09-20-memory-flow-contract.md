# Two linked flows

Write: observed event -> scoped evidence -> candidate lesson/procedure ->
comparison -> owner-service apply -> reread -> next actual use -> effect.
Read: task need -> small applicable memory -> relevant event -> exact source.
Not every episode becomes a fact or skill. Success once is not general proof.
Keep circumstances, attempts, outcomes, failure conditions and source locators.
Do not collect full transcripts or hidden reasoning.

## Selection contract

Legacy requests keep existing behavior. New task intent is a relevance hint,
never an authority, truth label or access grant.
Self-contained work can skip optional memories, not mandatory project/security rules.
Resume work points to existing continuity rather than duplicating checkpoints.
Procedures, decisions and incidents prefer different roles without hard exclusion.
Explicit role/history/query conditions cannot be softened by the hint.
Corrections and conflicting evidence remain checked before any shortened read.
Budgets cover the whole serialized response, including warnings and next actions.
Changing routing inputs invalidates cursors. Exact rereads stay available.
One invocation does not auto-run another search or model.

## Forgetting and observation

Archive/expiry/correction controls current presentation, not source deletion.
Keep rare warnings and counterexamples; popularity never proves truth.
Observations record returned resource fingerprints, revisions and line ranges.
Never persist raw bodies, query text, paths, credentials or freeform reasons.
Delivery is not acknowledged context retention, use or verified effect.
Consolidation remains a read-only worksheet; existing evolution owns mutations.
Source hashes prove byte identity, not truth or environmental validity.
