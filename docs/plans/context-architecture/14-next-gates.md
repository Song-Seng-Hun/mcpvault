# Remaining gates

This is design evidence, not implemented acceptance or routing.

## Candidate acceptance

Preservation obligations must bind source locators before accepted generation.
Do not retroactively label an older candidate as generated against new obligations.
Use versioned receipts for facts, mechanical checks and attributed semantic review.
Source backups use raw-byte revisions; do not borrow current-note body coordinates.
`fidelity-service.ts` requires an immutable source note and a current output note.
Do not weaken that requirement to inspect private bundle candidates.
Reuse `checkFidelityPreservation` through a private, revision-checked owner adapter.
`compilation-evidence.ts` already bounds locators and preserves prior obligations.
Its agent semantic reports are not server-certified truth or publication authority.
Only accepted output may reach a trusted staged-availability/cutover adapter.
Frontmatter staged/approved flags alone never enable or hide authoritative records.
No NAS-wide atomic transaction is promised; original TOC replacement stays last.

## Conditional routing

Reuse RetrievalService's evidence mode; keep its existing strict-query gate.
Optional semantic search already has a2s cancellation path and equal RRF k60.
`context_rules` validates authored literal conditions, not approval or rule authority.
Do not reuse situation-memory exclusions as new permanent document exclusions.
Approved applicability needs an explicit authority/revision binding.
Unverified labels remain soft relevance hints; fallback widens only soft filters.
Keep current authority, exact query conditions and source-family deduplication.
Existing private skill discovery filters remain active before candidate selection.
Guidance definitions have IDs, source revisions and owner-service access checks.
Group their discovery cards without loading all override bodies into task context.
The new routing packet must pin policy, catalog, authority and selected revisions.

## Operations

No native hook coverage or live migration is established by the P1d tests.
Current hook events omit PreToolUse; a feature flag is not a verified binding.
Trace the authenticated30s pulse deadline; saved checkpoint read/write succeeds independently.
Record-write guard callbacks must not reenter the serialized record read queue.
The operating account is verified; explicit source grants and acceptance are still required.
Measure metadata, continuations and rereads; English alone does not prove token savings.
