# Skills as procedural retrieval

A skill is versioned procedural knowledge with applicability, prerequisites and examples.
It is not factual evidence, authorization, an installed binary or a trusted system instruction.
Embedded RAG here means procedures integrated into task retrieval; embeddings are optional.
Separate procedure candidates from evidence, sharing identity, ACL and revision infrastructure.
Use concise English cards with verified Korean aliases; preserve exact names and the original query.

## Four exposure levels

Level0: small task-specific skill-group index, never the entire catalog.
Level1: matching cards with purpose, use/skip conditions, compatibility and read action.
Level2: selected procedure chapters and indispensable prerequisites.
Level3: exact examples/resources only when the step needs them.
Search metadata cannot elevate instruction authority.
Lexical/vector lookup and dependency edges are options, not mandatory costs on every request.
Version/project/host mismatch excludes applicability, not legitimate exact source lookup.
Resolve the reviewed current version through existing skill evolution.
Agent Skills progressive disclosure is a mechanism, not universal benefit evidence.[S8]

## Choose none

Compare no skill, relevant skill, wrong-version skill, length-matched noise and selected chapters.
SkillsBench reports average improvement but negative task-level effects too.[S9]
SWE-Skills-Bench reports limited gains in its software setting; do not pool unlike experiments.[S10]
Signal or Noise finds injection can hurt in WebDev and explicitly controls for length.[S12]
These findings justify local task/model/version tests; our router is not yet evaluated.
Reward verified outcome per total context cost, not loading a skill.
Mandatory project/security rules cannot be suppressed by predicted low value.
Optional guidance starts with zero or one procedure bundle; add only distinct necessary procedures.
Failures become review candidates, not automatically authored absolute rules.
Skill source scripts and external compression execution paths remain excluded.
See [agent and skill evidence](14-sources-agents.md); no local benchmark was run.
