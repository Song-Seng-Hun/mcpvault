# Implementation sequence

This deepens P2/P3 and scale infrastructure; it does not replace pending P1e delivery.
Research alone does not authorize implementation, deployment or pushing this proposal.

## Packages

R0: freeze workload, inspect actual index metadata, collect explainPlan and profile current paths.
R1: shared typed query plans and trusted candidate handles behind existing adapters.
R2: eligible predicates before top-k, measured scalar/vector indexes and disk-backed paging.
R3: task statecharts, selective skill cards and explicit no-skill decisions.
R4: exposure receipts and conservative deltas; strong suppression requires verified host support.
R5: scoped negative feedback and reversible repair proposals in existing exception board.
R6: bounded graph/agentic escalation after task holdout and resource gates.
Preserve old search compatibility and fixed five MCP tools.
Extend planned wiki.context_route/context_session, not parallel task or retrieval systems.
Existing source-read, compilation, continuity, skill evolution and change-set services keep write ownership.

## Invariants

Unknown ACL/runtime authorization -> deny private operation, never downgrade to public.
Unknown relevance -> wider safe discovery, not permanent exclusion.
Unknown retention -> rehydrate required context, not blind cooldown.
Unknown completeness -> partial coverage, not “no answer exists”.
Unknown feedback validity -> review, not automatic demotion.
Unknown backend memory -> benchmark under unchanged host guard, not optimistic activation.
No new paid model, transcript collection, background generation or corpus-wide LLM graph extraction.
Specialized ANN remains a measured alternative needing an adoption decision.
Current16GB hardware is not certified for the proposed tiers.
Later implementation retains target/build/full regression/NAS checks/fork-only delivery.

## Next decision

Approve planner-first architecture before detailed implementation tasks.
Start R0/R1: caching and skill suppression cannot recover sources already lost during candidate selection.
Keep new behavior disabled/shadow until its quality, privacy and host-support gates pass.
Research artifact checks cover physical chapter size and links, not runtime performance.
