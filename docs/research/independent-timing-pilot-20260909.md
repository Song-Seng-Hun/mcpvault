# 독립 조사 후 협업: 실제 모델 비교 파일럿 — 2026-09-09

## 결론

**이번 6문제 파일럿에서는 최종 결과가 동점이었다. 독립 조사 우월성이나 비용 절감은 입증되지 않았다.** 조기 공유 조건은 초기 11/12 → 최종 11/12, 지연 공유 조건은 초기 10/12 → 최종 11/12였다. 지연 공유 조건은 동료 의견을 받기 전에도 잘못된 인과 판단을 만들었으며, 대조 자료를 받은 후 이를 철회했다. 조기 공유 조건은 같은 잘못된 동료 의견을 처음부터 거부했다.

이는 독립 조사 기능을 없애거나 모든 협업에 강제할 근거가 아니다. 중립적인 목표·예산은 함께 정하고, 가설 노출을 늦추는 기능은 선택적으로 유지하되 **좋은 반증 자료를 선택하고 검토 후 원문 의미를 보존하는 절차**가 필요하다.

## 실제로 실행한 것과 하지 않은 것

- 실제 모델 세션 두 개: gpt-5.6-luna / medium, 새 문맥(fork_context=false), 순차 실행. 각 세션의 실제 로컬 turn_context 4개에서 설정 확인, function_call 0개 확인.
- early: 01a08588-b18c-7291-a410-38b67cdefb88; delayed: 01a0858a-b831-7592-aec8-2ef49a2f918a. 첫 세션 종료 확인 후 두 번째 시작, 두 세션 모두 종료.
- 각 모델이 자료 제목을 보고 최초 2개/문제, 검토 때 추가 1개/문제를 직접 선택했다. 조정자가 선택한 원문만 그대로 제공했다. 모델마다 4턴, 자료 요청 2회, 문서 레코드 18개.
- 자료·정답·점수 규칙은 모델 시작 전에 고정했다. [사전 규칙](independent-timing-preregistration.md), [가상 사례와 정답 기준](independent-timing-cases.json), 수정하지 않은 전체 프롬프트·응답 [early](independent-timing-early.json), [delayed](independent-timing-delayed.json), [측정값](independent-timing-metrics.json).
- **동료 가설은 사전에 작성한 실험 자극**이다. 여러 독립 연구자가 실제로 작성한 가설이 아니다. 네 개는 잘못됐고 두 개는 맞았다. 운영 사실이나 실제 제품에 대한 주장도 아니다.
- 실제 웹 검색·Gemini/Claude 호스트 비교·동시 다자간 협업·NAS 인증 계정 실험·모델의 실제 MCP 호출은 하지 않았다. 서버가 허용한 실험 계정인 척하지 않았다. 원문 선택/답변은 실제 모델 행동, 기존 MCP 격리 테스트는 별도 증거다.
- 운영 NAS 볼트·계정·서버 설정은 변경하지 않았다. 로컬 소스 저장소에는 평가 문서만 추가했다. 대화/암호 자동 수집, 새 모델 서비스, 생산 데이터 이동은 없다.

## 점수와 관찰

0 = 틀린/근거 없는 단정, 1 = 답의 방향은 맞으나 결정적 근거 또는 조치·조건 미흡, 2 = 읽은 결정적 자료로 조건까지 맞게 답함. 사전 규칙에 따라 주 평가자가 채점했으며 맹검 평가는 아니다.

| 문제 | 조기 공유 초기 → 최종 | 지연 공유 초기 → 최종 | 관찰 |
| --- | ---: | ---: | --- |
| c1 배포 장애 인과 | 1 → 1 | 0 → 1 | early는 증설을 기각. delayed는 먼저 증설을 우선했다가 대조 자료 후 철회. 두 최종 답 모두 bundle c7/c8의 통제된 차이를 충분히 활용하지 못하고 로그/fixture 차이를 넓게 남김. |
| c2 지원 조건 | 2 → 2 | 2 → 2 | 버전 하나로 전호스트 지원을 주장하지 않고 런타임·서버 capability 조건 유지. |
| c3 분모가 다른 정확도 | 2 → 2 | 2 → 2 | 전체 정답률 A70%/B45%와 응답 기준 B90% 구분. delayed 최종의 불필요한 유보는 아래 별도 지적. |
| c4 동시 조치의 인과 미확정 | 2 → 2 | 2 → 2 | 두 조건 모두 올바르게 미해결로 남김. 미해결 자체는 실패가 아님. |
| c5 WIP 경쟁 | 2 → 2 | 2 → 2 | 프로젝트 조정 구간 안의 재검사+CAS, 장기 잠금 및 분산 범위 한계 유지. |
| c6 폴더와 권한 | 2 → 2 | 2 → 2 | 폴더 이동을 권한 부여로 취급하지 않고 명시적 공유 검토를 제안. |
| 합계 | **11 → 11 / 12** | **10 → 11 / 12** | 동점은 동등성 증명이 아님. |

두 조건 모두 최종 5문제에서 온전한 주 결론, 1문제에서 부분 답변. 온전한 주 결론 5개 중 c4는 인과 미확정이라는 답이다. 신뢰성 평가이지 서버의 자동 사실 판정이 아니다.

- 초기 자료 선택은 6문제 중 5개에서 같았다. c1만 early가 운영요약+대조재현, delayed가 운영요약+변경목록을 선택했다.
- 최종 읽은 자료 집합도 5/6문제에서 같았다. c6만 early가 지원 문의, delayed가 화면 설명을 추가 선택했다.
- 양쪽 모두 6개 답에 대안 해석을 설명했다. 공통 출력 양식이 이를 요구했으므로 자발적 다각도 연구의 효과로 볼 수 없고, 의미적으로 좋은 대안 6개라는 점수도 아니다.
- early는 잘못된 가설 4개를 초기 답에 채택하지 않았다. delayed의 초기 c1 오류는 동료 의견 공개 **전** 발생했으므로 조기 합의의 사례로 세지 않았다.
- delayed는 공개된 동료의 c1 증설 가설에 동조하지 않고 추가 대조 자료를 반영해 기존 증설 우선 판단을 철회했다. 오류 정정 1건, early의 주 결론 정정은 0건(정정 기회 자체가 달랐다).
- 두 조건 모두 c4 미해결, c1 부분 상태를 유지했다. 억지 합의/확정 성공 처리하지 않았다.

## 주 결론 점수만으로 보이지 않는 문제

1. **이미 본 결정적 증거를 약화함:** delayed c3 최종은 실행집계가 대시보드 분모를 명시했는데도 “응답한 50문제만 분모로 한 보조지표일 가능성”이라고 유보했다. 주 수치·비교는 맞아 2점이지만, 확인된 사실을 미확인처럼 후퇴시킨 별도 품질 문제다.
2. **반박 문장의 부정이 뒤집힘:** early c5 최종 대안 설명은 파일 잠금만으로 충분하다는 해석이 초과 선점 기록과 “배치되지 않는다”고 썼다. 주 답변은 프로젝트 잠금을 올바르게 요구하지만 이 문구는 그 논리를 거스른다. 원본을 고치거나 감추지 않았다.
3. **조심스러움만으로 충분한 답이 되지는 않음:** c1에서 두 최종 답은 부당한 증설을 피했지만 동일 조건 c7/c8 비교로 가능한 구체적인 bundle 검증/교체 조치를 충분히 좁히지 않았다. 읽지 않은 c1-b의 AUTH_EXPIRED까지 알아야 한다고 벌점을 주지는 않았다.

검토는 새 자료를 추가하는 것뿐 아니라, 기존 자료의 조건·부정·정확한 관찰을 다시 대조해야 한다. 이 실험에서는 제품 코드를 자동 변경하지 않았다.

문자는 Unicode 코드포인트, 바이트는 UTF-8이다. 토큰 수가 아니다. 답변 크기는 원본 모델 JSON 문자열 기준이며 저장 파일의 부가 메타데이터/중복 close 상태를 포함하지 않는다.

시간은 조정자 관측·대기 지연을 포함하므로 모델 연산시간이 아니다. 토큰 사용량·금액·CPU/RSS·실제 디스크/네트워크 I/O는 측정하지 않았다. 표의 원문 바이트는 **논리적인 자료 전달량**이며 NAS I/O가 아니다. 지연 공유가 더 빠르거나 싸다고 결론내리지 않는다.

공통 검토 프롬프트는 양쪽에 같은 동료 가설을 제공했다. 따라서 early는 가설을 처음과 검토 때 두 번, delayed는 검토 때 한 번 접했다. 조기 노출과 반복 노출을 분리하지 못하며, 프롬프트 크기도 완전히 같지 않다. 이 차이를 사후 삭제하거나 출력을 재실행해 맞추지 않았다.

## 해석 한계와 다음 선택

두 세션 안의 6개 응답은 독립된 6회 반복 실험이 아니다. 조건마다 세션 하나, 고정 early→delayed 순서, 같은 모델, 읽기 제목이 비교적 명확한 수작업 가상 사례, 맹검 아닌 채점, 답변 양식과 반박을 요구하는 공통 안내, 반복 노출 차이가 있다. 웹 탐색 분기·장시간 조기 합의·진짜 동료의 독립적 증거 생산은 측정하지 않았다. ArcticSwarm 재현이나 통계적 유의성을 주장하지 않는다.

현재 판단: **독립 조사 기능은 선택형으로 유지하고, 가설보다 검증 가능한 근거를 먼저 제출하게 하는 방향을 유지한다.** 모든 작업의 협력을 의무적으로 늦추거나 독립 세션 수를 늘릴 근거는 없다. 다음 확대 실험은 필요할 때 별도 예산 하에 더 어려운 검색 코퍼스, 동일 총 노출 횟수, 순서 교차·반복, 블라인드 평가를 적용한다. 이번 요청으로 추가 세션을 계속 생성하지 않는다.
