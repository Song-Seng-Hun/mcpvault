# Independent-first timing pilot: preregistration

Frozen before model dispatch on 2026-09-09. Six synthetic research cases; sources are fictional controlled fixtures, not product claims.

Two fresh gpt-5.6-luna / medium sessions, fork_context=false, sequential. Arm A sees standardized peer hypotheses before choosing sources; arm B sees identical hypotheses only after provisional submission. Peer text is authored fixture, NOT another actual researcher. Same case order, menus, source-read budget, common review prompt and output contract. Each first selects two of four records/case, receives exact records, submits provisional answer/citations/alternative/uncertainty, then receives review and selects one remaining record/case before final answer. Max three distinct records/case, no web or filesystem/tool research. Coordinator brokers exact selected text; no adaptive hints. Maximum 24 model messages across both sessions, 15 minutes wall budget per arm; stop if exceeded, no selective reruns.

Record all prompts and unedited answers, dispatch-to-observed completion (including coordinator wait), codepoint/UTF8 sizes, broker read calls and source reads. Token count/actual compute/RSS unavailable: do not infer them. No production MCP/NAS writes or credentials. Model-stage source selection is real; this is not an authenticated MCP use test. The prior protocol tests are separate. Prompts restrict tools, not a security sandbox. No histories forked and no arm output given to the other.

Scoring fixed now: each case 0 incorrect/unsupported categorical answer, 1 main answer direction right but decisive evidence or conditions missing, 2 correct with decisive read citation and essential conditions. c1 requires c3 controlled bundle comparison (local case c1-c); c2 c2-c; c3 c3-b plus c3-d for full denominator/correct comparison; c4 c4-b for non-identifiability; c5 c5-a+c5-c or c5-b+c5-c; c6 c6-a+c6-d. Citation must have been delivered. Also count alternative causal explanation or interpretation actually evaluated (not mere listed name), early incorrect peer adoption (c1..c4), legitimate uncertainty, correction/worsening from provisional to final, and missing evidence. No forced winner on c4. Main-agent rubric scoring is unblinded; retain raw data. Six cases within two sessions are not independent replicated trials, no significance or general efficacy claim. Correct peer controls c5/c6 guard against indiscriminate opposition. Fixed deterministic order A then B is a confound; no randomized/counterbalanced multi-run claim.
