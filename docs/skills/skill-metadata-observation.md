# Potential impact and use

Impact combines declared effects and connection effects; claims cannot lower derived levels.
Private-read plus outbound-send can mean critical data disclosure under granted data flow.
Valid payment authority can mean critical asset impact up to the actual account limits.
Process, dependency, hook or MCP activation can have critical system consequences when unconfined.
Each consequence records assumptions. Missing capabilities can exceed this partial assessment.
Maliciousness and residual risk remain not_assessed; mitigation does not erase inherent impact.
Domain, policy and legal axes stay unknown without claims; claims are not review evidence.
Policy/legal review needs applicable version, jurisdiction, evidence and qualified judgment.

## Observations, not invented execution proof

Metadata reads do not count as procedure use. Successful procedure resolutions are counted.
Counts mean server completion, not acknowledgement, understanding or application.
Only newly saved shareable skill.experience records count as reported applications.
Identical accepted request retries do not double count reports.
Verified applications remain null; reports and source inspection are not execution receipts.
Observation scope: authenticated actor and selected document revision, not every host/tool call.
Source bundle revision guards metadata reads; counters are not whole-bundle execution evidence.
Storage: bounded process memory; restart resets the disclosed observation window.
Capacity exhaustion reports partial coverage. No observation means null, not zero lifetime use.
No private transcript or new persistent telemetry file is recorded.

Optional opaque taskId joins caller-reported co-use for that actor only.
Each task/skill revision pair is unique; current reads remove hidden or changed peers.
Task labels are not verified task identities. Counts never authorize loading or merging.
Shared experience content still requires existing explicit shareable=true and writer checks.
Do not place private context in that public/shared experience workflow.
Retirement remains not_evaluated: rare, quarantined or unobserved is not useless.
Review overlap, purpose, incompatible conditions, version, cost and observed outcomes first.
Future private persistence or verified execution accounting requires a separate host policy.
