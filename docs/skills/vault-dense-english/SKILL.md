# Vault dense English

Goal: less cumulative context without meaning loss. Style is not authority.
This is a Vault-specific profile, not unmodified upstream Caveman.

## Read one relevant chapter

- [Language](language.md): grammar, bilingual names, search identity; chapter1/3.
- [Precision](precision.md): conditions, evidence, uncertainty; chapter2/3.
- [Fiction](fiction.md): system expression versus canonical characters; chapter3/3.

Each chapter links its previous/next part. Read only what the task requires.
For service reads: `wiki.policy` topic=expression, then its selected readAction.
The service checks profile revision; read receipts do not prove understanding.

## Upstream differences

Source: [pinned Caveman](../caveman-source/SKILL.md); [terms](../caveman-source/LICENSE).
Revision and exact file hashes: [source manifest](../caveman-source/manifest.json).
Keep required progress updates; do not adopt upstream narration suppression.
Use English for new Vault prose, with necessary Korean names and scene exceptions.
Apply this profile to new persisted prose; upstream excludes persisted documents.
Preserve uncertainty and grammatical clarity; never remove meaningful hedging.
Do not load caveman-compress, external models, scripts or overwrite paths.
Engine-linked BSL code is excluded. Imported originals remain reference data.

## Validation boundary

Check exact names, conditions, units, examples and source locators before acceptance.
Mechanical tests check contracts, not translation correctness or model behavior.
No compression ratio, understanding gain or automatic migration is promised.
If uncertain, keep the original and request review of the candidate.
